# 한능검 기출 웹앱 — 사용법

## 처음 한 번

```
cd "01. 프로그래밍\01. Python\05. 웹앱"
pip install -r requirements.txt
python -m playwright install chromium      (테스트용. 설치가 안 되면 PC 의 Edge/Chrome 으로 자동 대체)
```

그다음 `웹앱_빌드.bat` 을 더블클릭하면 `dist\index.html` 이 생긴다. 이 파일을 브라우저로 연다.

## 새 시험지 추가

1. 문제지와 정답표 PDF 를 `inbox\` 에 넣는다. 파일명에 `78회` 처럼 회차가 있고,
문제지에는 `문제`, 정답표에는 `정답`(또는 `답지`) 이 들어 있어야 한다.
2. `새시험지_추가.bat` 실행.
3. `data\78\문항.csv` 를 엑셀로 열어 `검토필요=Y` 문항의 시대를 확인하고 Y 를 지운다.
4. `data\rounds.csv` 에 시행일을 적는다 (비워도 동작).
5. `웹앱_빌드.bat` 실행.

글자가 그림으로 된 문제지(65~69·73·74·78·79회가 그랬다)는 **OCR 로 처리**한다.
이 경우 PC 에 Tesseract 와 한국어 데이터(kor)가 설치되어 있어야 하며, 없으면 안내 후 건너뛴다.
Cowork 에 "inbox 의 새 시험지 추가해줘" 라고 맡기면 설치 없이 처리할 수 있다.

- 번호를 50개 다 못 찾으면 추출하지 않고 누락 번호를 알려 준다 → PDF 해당 쪽을 사람이 확인
- "순서로 추정한 문항" 이 나오면 그 문항 이미지를 한 번 열어 본다
- `[47~48] 다음 자료를 읽고…` 같은 공통 자료는 해당 문항 이미지 위에 자동으로 붙는다
- 이미 추출한 회차의 이미지만 다시 만들 때: `python src\extract_pdf.py --images-only --only 78` (시대·해설은 그대로)

## 해설 추가

### 풀이 화면에서 바로 작성 (권장)

1. 문항을 풀고 채점되면 해설 칸 오른쪽의 **작성**(해설이 있으면 **수정**)을 누른다.
2. 적고 **저장**. 이 브라우저에 저장되고 "작성함 · 반영 전" 표시가 붙는다.
3. 회차 화면 아래 **해설 파일 받기** → 다운로드 폴더에 `한능검_해설_날짜.json` 이 생긴다.
4. `해설_추가.bat` 실행. 다운로드 폴더와 `inbox\해설\` 에서 파일을 찾아 `문항.csv` 에 반영하고 다시 빌드한다.
   화면에서 고친 해설은 기존 해설을 **덮어쓴다**(덮어쓰기 전 `_archive\해설반영_날짜시각\` 에 백업).
5. 반영된 해설은 다음에 화면을 열 때 "반영 전" 목록에서 자동으로 빠진다.

반영 전 해설은 이 브라우저에만 있으므로, 다른 기기로 옮기기 전에 먼저 반영해 둔다.

### 해설 PDF

1. 해설 PDF 를 `inbox\해설\` 에 넣는다. 본문에 `75회 5번` 형식이 있어야 한다. 앞의 큰 번호는 무시된다.
2. `해설_추가.bat` 실행. 이미 해설이 있는 문항은 건너뛴다 (덮어쓰려면 `python src\import_explanations.py --force`).

해설을 직접 고치려면 `문항.csv` 의 해설 칸을 엑셀에서 수정하고 `웹앱_빌드.bat` 을 실행한다.

## 기록 백업

기록은 이 PC 의 이 브라우저에만 저장된다. 회차 화면 아래의 "백업 파일 받기"로 JSON 을 받아 두고,
다른 기기에서는 "백업 불러오기"로 합친다 (같은 기록은 중복되지 않음).
단일 HTML 테스트본(ver2)에서 쌓은 기록은 주소가 달라 자동으로 보이지 않을 수 있다 — 그때도 백업으로 옮긴다.

(`python -m playwright install chromium`). 받지 못해도 테스트는 Edge → Chrome 순으로 대신 실행된다.

python _test\run_tests.py
