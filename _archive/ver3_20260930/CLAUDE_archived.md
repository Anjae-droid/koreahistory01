# 05\. 한능검 기출 웹앱 — 작업 규칙

한국사능력검정시험(심화) 기출을 회차별로 풀고, 문항 반응(A\~D)과 오답 1줄 기록을 남겨
학습 코치 채팅에 붙여넣을 텍스트로 내보내는 로컬 웹앱.
"무엇을 왜" 는 `한능검웹앱\_기획.md`, 사용법은 `README\_한능검웹앱.md` 에 있다.

상위 `01. 프로그래밍/CLAUDE.md` 의 규칙을 그대로 따른다. 아래는 이 폴더에만 해당하는 규칙이다.

## 1\. 폴더 역할

|경로|역할|수정|
|-|-|-|
|`src/template\_round.html`|회차 풀이 화면 (디자인·기능 전부)|여기서만 고친다|
|`src/template\_index.html`|회차 선택 화면|여기서만 고친다|
|`src/build.py`|`data/` → `dist/` 생성||
|`src/extract\_pdf.py`|시험지 PDF → `data/<회차>/`||
|`src/import\_explanations.py`|해설 PDF → `문항.csv` 해설 칸||
|`src/era\_keywords.py`|시대 자동 분류 키워드|분류가 틀리면 키워드만 조정|
|`data/rounds.csv`|회차, 시행일|사람이 편집 가능|
|`data/<회차>/문항.csv`|번호, 정답, 배점, 시대, 검토필요, 해설|사람이 엑셀로 편집 가능|
|`data/<회차>/img/qNN.jpg`|문항 이미지 (원본 PDF 에서만 추출)|교체만|
|`dist/`|생성물. 브라우저로 여는 곳|**절대 직접 수정 금지**|
|`inbox/`, `inbox/해설/`|새 PDF 투입구. 처리 후 `done/` 으로 이동||
|`\_test/run\_tests.py`|브라우저 회귀 테스트||
|`\_archive/verN\_<날짜>/`|구버전 보관||

## 2\. 반드시 지킬 규칙

* 파일을 고치기 전에 `\_archive/verN\_<날짜>/` 에 먼저 복사한다. `data/` 의 CSV 도 포함.
* **지시하지 않은 것은 고치지 않는다.** 디자인 톤(베이지 배경·적갈색 헤더·둥근 카드)은
사용자가 한 번 되돌리라고 한 이력이 있다 (ver1 → ver2). 지시 없이 바꾸지 않는다.
* 디자인·기능 변경은 `src/template\_\*.html` 에서만 하고 `웹앱\_빌드.bat` 으로 전 회차에 반영한다.
회차별 HTML 을 따로 고치지 않는다.
* 시각 요소(문항 이미지)는 공식 문제지 PDF 에서 추출한 것만 쓴다.
* CSV 는 UTF-8 with BOM (엑셀 한글 깨짐 방지).
* `.bat` 내용은 ASCII 만. 한글 경로는 배치파일에 쓰지 않고 Python 에서 처리한다.
* 결정론적 처리(자르기·정답 파싱·검증·빌드)는 Python. 비정형 판단(시대 분류 검토, 해설 작성)은 사람 또는 LLM.
* 외부 네트워크 호출·인증키 없음. `template\_\*.html` 에 `fetch` 를 넣지 않는다 (`file://` 에서 막힘).
데이터는 `<script src="data/...js">` 로 읽는다.
* 규칙·템플릿·빌드를 바꾼 뒤에는 `python \_test\\run\_tests.py` 를 실행한다.

## 3\. 학습 코치와 맞물린 부분 (바꾸면 코칭 방에도 알릴 것)

* 문항 반응 4분류: A 바로 맞음 / B 헷갈렸는데 맞음 / C 두 선지에서 틀림 / D 아예 모름.
정답이면 A·B, 오답·미응답이면 C·D 만 고를 수 있다.
* 1줄 기록 양식: `회차-번호 / 시대 / 내 답·정답 / 두 선지를 구분하는 근거` (D 는 정답 선지 핵심 키워드).
B·C·D 는 필수, A 는 선택.
* 연습 모드(반 회차)는 시간 기록 없음. 실전 모드만 80분 타이머.
* 결과 화면 "기록 복사" 텍스트 형식은 코치가 파싱하는 입력이다. 형식을 바꾸면 코칭 방에 알린다.

## 4\. 알려진 한계

* 기록은 브라우저 localStorage(`hkh.sessions.v1`)에만 저장된다. 기기·브라우저가 바뀌면 안 보인다.
홈 화면의 백업/불러오기로 옮긴다.
* 텍스트 레이어 없는 스캔 PDF(67·68·69·73·74회)는 자동 추출 불가.
* 좌표는 70\~77회 문제지(729×1032pt, 2단) 기준. 레이아웃이 다르면 문항 수가 50이 안 나와 중단된다.
* 시대 분류는 키워드 초안이다. `검토필요=Y` 문항은 사람이 확인한다.
* `rounds.csv` 의 시행일은 확인되지 않은 값이 들어 있다 (확인 필요).
